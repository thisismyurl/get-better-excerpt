# Get Better Excerpt

Drop-in replacement for `get_the_excerpt()` / `the_excerpt()` that returns whole words instead of mid-word cuts.

WordPress core truncates excerpts by character count, which can break words in the middle. This plugin truncates by word boundary so excerpts read cleanly.

[![WordPress.org](https://img.shields.io/wordpress/plugin/installs/get-better-excerpt.svg)](https://wordpress.org/plugins/get-better-excerpt/)

## Features
- Word-boundary excerpt truncation.
- Same API surface as `get_the_excerpt()` and `the_excerpt()`.
- Configurable word count.

## Status
Maintenance mode. Plugin is open for adoption — see WordPress.org listing.
